# 離線填報 E2E 驗收清單

Must-have #4：低連線環境下填報，恢復連線後同步。

## 前置

- [ ] 至少以**連線**開啟 App 一次（危機設定、active-window 已快取）
- [ ] （可選）已下載離線瓦片與建物 footprint

## 步驟

1. **離線**
   - [ ] 開啟飛航模式或 DevTools → Offline
   - [ ] 地圖顯示離線 banner；可進入已下載區域（若有）
2. **填報**
   - [ ] 新增回報（建物或 GPS + 照片）
   - [ ] 提交成功；離線佇列顯示 1 筆 pending
3. **恢復連線**
   - [ ] 關閉飛航模式
   - [ ] 佇列自動或手動「同步」成功
4. **可見性**
   - [ ] 同一 bbox 內地圖出現新 pin（或自己提交後 refresh）
   - [ ] Ops 地圖／Dashboard 可查到該筆（依危機／歸檔範圍）

## 已知限制

- 離線時無法**首次**下載 footprint（需連線）；已下載 scope 內可平移仍顯示。
- 6s 輪詢僅 sync **本機佇列**；他人新 pin 需連線 + 30s 週期 refresh 或平移 bbox。

## 教學影片建議鏡頭

1. 飛航模式 ON → 填一筆 → 佇列
2. 飛航模式 OFF → 同步成功 toast
3. 地圖 pin 出現 + Dashboard 列表一行
