# 離線行為與地圖限制

## 目前已支援（C1 + C1.5）

| 能力 | 說明 |
|------|------|
| 危機快照 | 至少連線開啟一次 → `active-window` 寫入 IndexedDB |
| 離線新增回報 | 相片 + payload 入佇列，上線後 `syncQueue` |
| 周邊地圖預下載 | 以定位／地圖中心為圓心，**半徑 2 km**（外接方框約 **4×4 km**）、z14–z17 的 OSM 瓦片 |
| 覆蓋率檢查 | 以所需瓦片集合計算已快取比例（顯示於地圖下載面板） |
| 離線區域導覽 | 橘色（連線預覽）／藍色（已存）方框；離線點選後飛至 z17，可自由縮放（超出快取可能灰屏） |
| PWA / Service Worker | **離線可開首頁**（預快取 `index.html` + assets；runtime cache OSM tiles + 必要 API） |

## 地圖為何會變灰？

底圖使用 **OpenStreetMap 線上瓦片**（`tile.openstreetmap.org`）。離線時：

1. 瀏覽器只能顯示已快取的瓦片。
2. 平移/縮放到未快取區域會請求新瓦片。
3. 請求失敗後 Leaflet 會出現灰底。

## 現場建議流程（一般民眾/救援隊）

1. **有網路時**開啟 App 並允許定位。
2. 在地圖左上面板按「下載周邊地圖」。
3. 等待覆蓋率足夠（建議 > 90%）。
4. 前往現場離線填報；地圖可在下載區內持續使用。

## 如何驗證「離線也能開首頁」？

1. 線上開啟首頁一次，等待載入完成。
2.（建議）按「下載周邊地圖」到覆蓋率足夠。
3. 關閉分頁或重新開新分頁。
4. 切成離線（飛航模式 / DevTools Offline）。
5. 重新開 `https://beacon.cila.workers.dev/`：應可進入首頁並看到介面（地圖顯示以已快取瓦片為主）。

## 技術備註

- 瓦片儲存在 IndexedDB：`map_tiles`。
- 區域中繼資料儲存在 IndexedDB：`map_regions`。
- 共用 DB 版本提升至 `v3`（`openOfflineDb()`）。
- 若下載不完整，離線仍可填報，但地圖可能局部灰屏。

## 合規與範圍

- 預下載功能需遵守 OSM [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)。
- 目前設計是「**局部 AOI** 快取」（**半徑 2 km**，地圖上為外接正方形約 **4 km 邊長**），不是整城市/全國離線包。

## 與產品模型的關係

`unspecified` 階段仍可任意地點提交回報。地圖快取只影響離線可視化體驗，不影響提交規則；管理員日後劃定範圍/時間窗僅影響顯示篩選。
