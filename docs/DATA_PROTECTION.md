# 資料保護與隱私（投稿摘要）

## 技術措施（已實作）

| 項目 | 作法 |
|------|------|
| 回報者識別 | `reporter_hash`（裝置指紋單向 hash），不存姓名／電話 |
| 照片 | 私有物件儲存（R2／本機），匯出以 signed URL 或後台權限存取 |
| 編輯權 | 僅同裝置可編輯／刪除自己的回報 |
| 營運存取 | JWT + 角色（admin / lead / coordinator）與分區範圍 |

## 資料保留（敘述）

- 回報與影像留存至營運方依危機結案後之內部政策刪除或匿名化（提案中說明預期 24–36 個月滾動窗口，可配置）。
- `unspecified` 桶內回報在正式歸檔前仍完整保留，歸檔僅寫入 `report_crisis_links`，不刪原始列。

## UNDP Personal Data Protection Policy 對照（精簡）

| 原則 | 對應 |
|------|------|
| 合法／公平／透明 | 公開 PWA；回報前說明用途與照片用途 |
| 目的限制 | 僅災害損害評估與協調，不作行銷 |
| 資料最小化 | 不要求帳號；可選建物／GPS／文字地標 |
| 準確性 | 允許回報者編輯自己的提交 |
| 儲存限制 | 見上「資料保留」 |
| 完整性與機密 | HTTPS、後台 RBAC、私有儲存 |
| 問責 | Ops 稽核 log（歸檔、審核、分區變更） |
